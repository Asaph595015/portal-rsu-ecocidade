ECOCIDADE — PORTAL E AVALIAÇÃO DO CLIENTE

CORREÇÃO DE PUBLICAÇÃO E RELATÓRIO PDF

1. O arquivo resultado.html consulta a API /api/avaliacoes. Essa rota existe no servidor Flask (server.py). Se o projeto for publicado como site estático no Netlify ou GitHub Pages, a rota retornará 404 porque esses serviços não executam o servidor Python.
2. Para avaliações compartilhadas entre clientes e equipe, publique este projeto como serviço Web Python no Render. O arquivo render.yaml contém a configuração do serviço, comando gunicorn e disco persistente.
3. No Render, crie o serviço usando o repositório que contém server.py, requirements.txt e render.yaml. Configure ADMIN_PASSWORD com uma senha forte. O disco persistente mantém as avaliações após novos deploys.
4. Depois do deploy, teste https://SEU-DOMINIO/api/avaliacoes. Deve retornar [] se ainda não houver avaliações, ou uma lista JSON se houver envios. Não deve retornar 404.
5. Cliente: https://SEU-DOMINIO/feedback.html
6. Equipe/desenvolvedor: https://SEU-DOMINIO/resultado.html

EXPORTAÇÃO EM PDF
Na página resultado.html, clique em “Exportar relatório em PDF”. O navegador abrirá a janela de impressão; selecione “Salvar como PDF” como destino. O relatório inclui o resumo, a visão por seção e as avaliações individuais.

OBSERVAÇÃO IMPORTANTE
Os envios automáticos usam POST /api/avaliacoes e são armazenados no servidor. “Salvar neste dispositivo” continua sendo apenas um rascunho local no navegador do cliente.

ESTRUTURA PRINCIPAL
- server.py: aplicação Flask e API de avaliações.
- feedback.html / js/feedback.js: formulário do cliente.
- resultado.html / js/resultado.js: painel da equipe e exportação em PDF via impressão do navegador.
- render.yaml: configuração de publicação no Render.
